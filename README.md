# Statistical and Research Methods, Prof. Nitzan Shahar 2026
This is the website that accompanies the course "Statistical and Research Methods" in the graduate program in the School of Psychology at Tel Aviv University.


## How the site is built

The pages are generated by `site/build.py` from the lecturer's course folder (read-only) and from `site/site.json`, which lists what has been published. Only published items appear on the site. Generated output: `index.html`, `week-*.html`, `assets/`, `decks/`, `files/` — do not edit these by hand.
